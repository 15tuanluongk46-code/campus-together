# Original Campus Together assets

All geometry, material colour palettes, numeric badge shapes, facial design,
decorative symbols and animation trajectories in the Task 2 GLBs are original
procedural work created for Campus Together on 2026-10-04. No external mesh,
texture, mocap, trademark, character, or font asset was used.

Editable source and reproducible generators: `assets/source/` at project root.
Tool: Blender 5.2.1 LTS, native glTF 2.0 exporter. Generated exports use ordinary
metallic-roughness PBR; no runtime procedural material or Blender constraint is required.
